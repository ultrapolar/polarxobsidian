Accuracy pass: adaptive detection, OCR retries, dual-search matching, confidence

Accuracy-first upgrades (slower where it buys correctness):

- Resolution-adaptive detection: MIN_HIGHLIGHT_AREA and morphology kernels
  are now defined at DETECT_REFERENCE_WIDTH and scaled to the actual image
  width, so scans/photos/DPIs detect the same physical highlight identically.
- Confidence-gated OCR retries (run_ocr_best): pages reading below
  OCR_RETRY_MIN_CONF are re-OCR'd with the original image, auto-PSM, and a
  1.5x upscale; the highest-confidence variant wins (boxes mapped back).
  Also removed a redundant second Tesseract pass per page (full_text is now
  derived from the word list), roughly halving base OCR time.
- Reference matching now searches both the in-order window AND the whole
  book for every sentence, preferring the global hit only when clearly
  better (REFERENCE_GLOBAL_MARGIN) - eliminates window mis-anchoring.
- Per-highlight confidence: blend of fuzzy match score (reference-corrected
  share) and Tesseract word confidence (rest). Surfaced as Confidence +
  REVIEW-flagged rows in the XLSX, and a confidence block + review_rows in
  the analytics JSON. Readwise CSV stays clean.
